# 输出模板

```markdown
# {模型名称} 架构解析

## 整体概述
一段话：架构类型、规模、设计主线（如"以 MoE + MLA 压缩推理成本"）。

## 逐节点解析

### 节点 N：{节点名称}
- **是什么**：……
- **内容是什么**：……（硬数字带来源）
- **做什么**：……
- **目标是什么**：……
- **意义是什么**：……（含与替代方案的对比）

### ……（按整体 → 输入侧 → 核心块 → 输出侧 → 训练/推理 顺序排列）

## 不确定项与未公开信息
| 项目 | 状态 | 已尝试的验证路径 |
|---|---|---|
| …… | 未公开 / 来源冲突 | 查了论文 X、官方 config，均无 |

## 架构流程图
见附件 / 下图。
```

## 要求
- 每个节点的五条一条不缺；"内容"条必须有具体数字或明确写"未公开"。
- 事实与推断分开：推断处标注"（推断）"。
- 不确定项清单不为空时也要保留该节；为空则写"无"。
